# INVAL Free — отмена судебного приказа

**Версия 1.5** · [Рабочий генератор](https://inval.sbs/otmena-prikaza/) · [Поддержать проект](https://inval.sbs/support/)

Бесплатный инструмент для подготовки возражений относительно исполнения судебного приказа по **ГПК РФ**. Поддерживает загрузку PDF, JPG, PNG и WEBP, распознавание текста, проверку реквизитов, ручное исправление и создание DOCX. PDF создаётся штатной функцией браузера «Печать → Сохранить в PDF».

## Приватность

- Файлы обрабатываются JavaScript-кодом непосредственно в браузере, **без загрузки документа в API INVAL**.
- PDF.js и Tesseract.js, их Web Workers и языковые модели должны обслуживаться локально с того же веб-сервера; при работе генератора CDN не требуются.
- По текущему исходному коду нет отправки введённых данных, аналитики, localStorage или sessionStorage.
- Это **не гарантия полной анонимности**: IP-адреса и технические сетевые запросы могут фиксироваться веб-сервером, хостингом или браузерными расширениями. Проверяйте реальные сетевые запросы в DevTools.

## Самостоятельный запуск

Нужны Python 3, Bash, curl и доступ в интернет **один раз для скачивания открытых библиотек**.

```bash
bash scripts/install-vendors.sh otmena-prikaza/vendor
sha256sum -c VENDOR_SHA256SUMS
python3 -m http.server 8080
```

Откройте `http://localhost:8080/otmena-prikaza/`.

Пути в исходниках намеренно начинаются с `/otmena-prikaza/`: это позволяет сравнивать код с публичным сайтом, не переписывая исходники под локальный запуск. На хостинге разместите папку `otmena-prikaza` в корне сайта.

**Не открывайте `index.html` через `file://`: ES-модули и Web Workers требуют HTTP(S).**

Поставляемые `scripts/install-vendors.sh` и `VENDOR_SHA256SUMS` позволяют восстановить локальные библиотеки и сравнить их содержимое с тем, что было на сервере INVAL при экспорте. В ZIP включены только собственные исходники; сторонние библиотеки скачиваются отдельно из публичных релизов.

## Юридические ограничения

Генератор рассчитан на типовые судебные приказы по ГПК РФ (ст. 112, 128–129). Он не предназначен для приказов по КАС РФ, АПК РФ или обычных судебных решений. Вывод необходимо проверить самому; программа не заменяет консультацию специалиста.

## Что не опубликовано

Этот репозиторий **не содержит** серверной части закрытой биржи INVAL, баз пользователей, переписки, настроек Nginx, почты, персональных документов, ключей и конфигураций. Код главной страницы и страницы донатов тоже не входят в состав генератора.

## Как сравнить с сайтом

Файл `SOURCE_SHA256SUMS` сформирован из трёх живых файлов генератора при экспорте. Можно сравнить их с ответами `https://inval.sbs/otmena-prikaza/{index.html,app.js,style.css}` (учитывая, что файлы могут обновляться). `VENDOR_SHA256SUMS` описывает используемые сторонние локальные ресурсы. История GitHub сама по себе не доказывает, что сервер всегда исполняет идентичный код.
